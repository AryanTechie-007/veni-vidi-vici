## 📡 MeshSync — Offline Emergency SOS Relay

**MeshSync** is a decentralized, serverless disaster-response communication platform that creates an ad-hoc, peer-to-peer (P2P) mesh network over **Google Nearby Connections** (`P2P_CLUSTER`). It enables victims, citizens, and search-and-rescue (SAR) teams to exchange life-saving distress signals, casualty counts, and triage updates without cellular service, Wi-Fi infrastructure, or centralized servers.

---

## 🚀 Key System Architecture

1. **Decentralized Cryptographic Identity (`DeviceIdentity`)**:
   - Minted unique device origin and monotonically incrementing sequence counter.
   - Message IDs computed deterministically via `sha256(origin + seq)` truncated to 16 hex characters, ensuring collision-free deduplication offline.
2. **Two-Part Packet Architecture (`MeshMessage`)**:
   - **Core (Frozen at creation)**: Immutable payload containing origin, timestamp, category, headcount, optional note, GPS coordinates, and reference IDs.
   - **Envelope (Travel State)**: Mutable hop counters and TTL expiration timestamps.
3. **Store-and-Forward Flooding Router (`MeshRouter`)**:
   - Automatic multi-hop relaying where every smartphone acts as an encrypted packet courier across the disaster perimeter.
   - Automatic ACKs generated by responder devices and flood-propagated back to victims.
   - CANCEL packets that purge resolved incidents across all network nodes.

## 🎨 v0.2 Minimalist Frontend Redesign

The user interface has been completely redesigned with a **clean minimalist aesthetic**:

- **Pure Minimalism & Zero Glassmorphism**: Removed all glassmorphic cards, gradients, and heavy shadows in favor of flat, clean borders, crisp contrast, and functional layouts.
- **Color Scheme**:
  - **Black Background for Dark Mode**: True black (`#000000`) for OLED power savings in emergency situations.
  - **Clean White for Light Mode**: `#FFFFFF` with high contrast.
  - **Bold Red SOS Button**: High-visibility emergency red (`#D32F2F`) for the primary distress trigger.
  - **Dark / Light Mode Toggle**: Instant switching between dark and light themes.
- **Typography**: Clean **Arial** font family used throughout the interface.
- **Victim & Responder Views**:
  - Direct 1-tap SOS trigger and simple emergency category presets (Medical, Trapped, Fire, Supplies).
  - Streamlined headcount stepper and landmark note input.
  - Clear delivery tracking (*Broadcasting* $\rightarrow$ *Relaying* $\rightarrow$ *Responder Acknowledged*).
  - Search & Rescue incident triage dashboard with live metrics and resolution actions.
- **Interactive Localhost Web Simulator**: Run on `http://localhost:8000` for live browser verification.
